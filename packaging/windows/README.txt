Wordy for Windows (x86_64, Windows 10 or later)

Wordy.exe runs from anywhere: keep it in this folder or move it to a folder of
your choice, then double-click it. Pin it to Start or the taskbar from there.

The build is not signed, so SmartScreen will object the first time. Click
"More info", then "Run anyway". That happens once per copy of the file.

Projects live in %USERPROFILE%\Wordy, one folder each, and settings in
%APPDATA%\wordy. Wordy needs DirectX 11, which every supported Windows has.

This build is compiled and launch-checked on GitHub's Windows runners only.
If something looks wrong, please say so: https://github.com/samjohnduke/wordy/issues
